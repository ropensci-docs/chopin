# Check the class of an input object

This function checks the class of an input object and returns "raster"
if it is a raster object, or "vector" if it is a vector object.

## Usage

``` r
.check_character(input)
```

## Arguments

- input:

  The input object to be checked

## Value

A character string indicating the class of the input object ("raster" or
"vector")
