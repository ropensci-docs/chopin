# Merge adjacent grid polygons with given rules

Merge boundary-sharing (in "Rook" contiguity) grids with fewer target
features than the threshold. This function strongly assumes that the
input is returned from the internal function `par_make_grid`, which has
`"CGRIDID"` as the unique id field.

## Usage

``` r
par_merge_grid(
  points_in = NULL,
  grid_in = NULL,
  grid_min_features = NULL,
  merge_max = 4L
)
```

## Arguments

- points_in:

  `sf` or `SpatVector` object. Target points of computation.

- grid_in:

  `sf` or `SpatVector` object. The grid generated by the internal
  function `par_make_grid`.

- grid_min_features:

  integer(1). Threshold to merge adjacent grids.

- merge_max:

  integer(1). Maximum number of grids to merge per merged set. Default
  is 4. For example, if the number of grids to merge is 20 and
  `merge_max` is 10, the function will split the 20 grids into two sets
  of 10 grids.

## Value

A `sf` or `SpatVector` object of computation grids.

## Note

This function will not work properly if `grid_in` has more than one
million grids.
