# Mildly clustered points in North Carolina, United States

Mildly clustered points in North Carolina, United States

## Usage

``` r
ncpoints
```

## Format

A data frame with 2,304 rows and two variables:

- X:

  X coordinate

- Y:

  Y coordinate

## Source

sf package data `nc`

## Note

Coordinates are in EPSG:5070 (Conus Albers Equal Area)
